🏬 Hotel Room Booking System

A Python-based Hotel Room Booking System that helps manage room reservations, customer records, check-ins, check-outs, billing, and booking history using JSON file storage.

Features

- View Available Rooms
- Book Rooms
- Search Bookings
- Check-In Management
- Check-Out Management
- Cancel Bookings
- Generate Customer Bills
- Booking History Tracking
- Dashboard with Room Statistics
- JSON-Based Data Storage

Technologies Used

- Python 3
- JSON
- Object-Oriented Programming (OOP)
- File Handling

How to Run

1. Clone the repository.

2. Navigate to the project folder.

3. Run the application:

python hotel_room_booking.py
